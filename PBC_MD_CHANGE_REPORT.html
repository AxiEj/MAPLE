C-rescale 科学边界

dλ = −(βλ)/(2τP) · (P0 − Pint − kBT/(2V)) dt + √(kBTβ/(2τP)) dW

变量选择

使用 λ=√V，噪声幅度不依赖 V；比简单 log/volume Euler 更适合做可审计 production path。

md/barostat/crescale.py:7-29

速度缩放

cell 与 positions 按 μ 缩放，velocities 返回 v/μ，对齐 scaled momenta form。

md/barostat/crescale.py:31-35,287-290

诚实边界

这是 isotropic hydrostatic barostat，不是 Parrinello-Rahman/MTTK/shear/anisotropic cell sampler。

md/barostat/crescale.py:47-60

Release truth ladder

L1 Static

代码/文献审阅：可进入 validation，但不能 claim production.

L2 Unit

fake/LJ 层：admission、semantics、restart、C-rescale gates.

L3 Engine

non-smoke LJ acceptance matrix：10 classes，0 fail，0 skip。

L4 Backend

每个 required backend current clean commit PASS，并通过 aggregate checker。

Checklist 明确：static review、quick smoke、LJ-only、stale artifacts 都不能写成 “production validated”。

验证矩阵：每类风险怎么被锁住

结论

当前分支的科学目标是：PBC-MD 路径在已支持范围内更严格、更可审计；不支持或未验证的状态明确拒绝或标记 experimental； release 声明必须绑定同一 clean commit 的验证 artifact。换句话说：这次改动把“能跑”提升为“前提清楚、失败封闭、证据可追踪”。
