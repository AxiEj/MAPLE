必须修 / 必须 gate 项

优先级问题影响建议 gate / 修复
P0 release blocker缺少真实后端 production acceptance artifact。单位、stress、cutoff、PBC graph 都依赖真实 calculator 行为；没有报告不能证明不会假模拟。每个 production backend 跑完整 validation/thresholds.toml；要求 overall=PASS、n_skip=0、barostat_clamp_count=0，并把 artifact id 写入 release notes/manifest。
P1AIMNet2 Ewald/PME MIC gate 只覆盖 5 Å local descriptor，不覆盖 hidden real-space cutoff。long-range backend 内部 cutoff/accuracy/cell 组合可能有隐藏约束。DSF 优先作为 production 默认；Ewald/PME 单独真实后端验收，并在 manifest 标明 MIC gate 范围。
P1/P2WRAP_BOUNDARY_EPS near-boundary negative crossing 语义未钉死。极小边界下 image flag 可能延迟更新；物理影响很小，但严格轨迹语义不够明确。补 scaled=-eps/2、1+eps/2、multi-step accumulate regression；明确 snap policy，并保证 wrapped fractional 压回 [0,1)。
P2Langevin+NPT pressure 使用 full KE，COM 可能被 Langevin noise 重新激发。小体系/长时间 pressure 可能混入 COM bath artefact。将 Langevin+NPT 标 experimental；或每步 COM projection；或 pressure kinetic term 扣除 COM KE。
P2Langevin thermo 主列可能是 carried velocity，sync 是附加列。下游脚本可能读错温度/能量。把 raw 列改名 *_carried，或让 sync 列成为 Langevin path 主 thermo。
P2DCD wrapped-only，不携带 image flags。用户可能拿 DCD 做 MSD/diffusion 得到假结论。banner/docs 明确：DCD 用于 wrapped visualization；扩散/连续轨迹使用 unwrapped XYZ/RST。
P3NVE drift threshold 较松，真实后端 baseline 未见。短 LJ reference 不能证明长期真实后端稳定。增加 longer-run LJ NVE、多 seed NVT/NPT、真实后端 smoke + full gate。

C-rescale 科学边界

dλ = −(βλ)/(2τP) · (P0 − Pint − kBT/(2V)) dt + √(kBTβ/(2τP)) dW

正确方向

λ=√V、常幅噪声、NP stride 全 interval propagation、velocity scaled momenta，方向与 stochastic cell rescaling 文献一致。

md/barostat/crescale.py:7-35

不能夸大

实现是 reversible Euler，不是 symmetric Trotter；它是 isotropic hydrostatic，不是 Parrinello-Rahman/MTTK/aniso cell。
