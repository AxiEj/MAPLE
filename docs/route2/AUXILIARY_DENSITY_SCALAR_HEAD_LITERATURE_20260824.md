# Auxiliary-density scalar-head literature checkpoint (2026-08-24)

This note records the literature decision behind the next MACE-MDP +
MACE-POLAR hybrid experiment. It is not an admission artifact and contains no
experimental solvation target.

## Current evidence

The original point/GTO/ADT source family is terminal for quantitative cavity
MEP: the matched-QM response audit resolves large spatial errors even when the
total molecular polarizability is accurate. A twelve-molecule Coulomb-fitted
auxiliary-density oracle has now shown 1.05--3.72% constrained exterior-MEP
error for eleven molecules, but the locked gate remains failed because methane
has a 19.63% low-signal relative error.

## Literature-aligned representation

The following recent work supports an atom-centred radial/spherical auxiliary
density representation rather than another point-multipole correction:

1. **SALTED and symmetry-adapted density response** represent the density and
   its electric-field response in atom-centred radial functions times real
   spherical harmonics, with the fitting metric chosen for the downstream
   observable. The 2025 response paper makes the response itself equivariant
   rather than reconstructing it from a molecular polarizability alone.
   <https://arxiv.org/abs/2501.11019>
   <https://salted.readthedocs.io/en/latest/theory/>

2. **Design Space of Self-Consistent Electrostatic MLIPs** treats learned
   density variables as the common representation connecting a scalar energy
   and self-consistent electrostatics. Its main lesson for MAPLE is that the
   response source must be generated by the scalar construction rather than
   appended as an unrelated residual head.
   <https://arxiv.org/abs/2603.14700>

3. **Towards A Universally Transferable Acceleration Method for DFT** predicts
   atom-centred auxiliary-density coefficients with an E(3)-equivariant model.
   It provides a current concrete precedent for species-dependent auxiliary
   heads and for using density-fitting coefficients instead of a full AO
   density matrix or Hamiltonian.
   <https://arxiv.org/abs/2509.25724>

4. The **ddX theory contract** assumes the source density is supported inside
   the cavity. Gaussian auxiliary functions do not have compact support. A
   boundary-MEP oracle such as symmetric PCMSolver therefore gives the cleanest
   representation-only energy metric until an exact ddX/Psi4-style general
   density interface, including both source objects required by ddX, is bound.
   <https://ddsolvation.github.io/ddX/md_docs_theory.html>

## MAPLE design decision

The retained architecture is:

```text
frozen MACE-MDP geometry features
        -> species-aware equivariant auxiliary-density scalar head
        -> one field-energy scalar G_theta(R, u)
        -> permanent and induced density from derivatives of that scalar
        -> exact charge/first-moment constraints in a cavity-independent metric
        -> boundary MEP
        -> reciprocal continuum scalar
```

The old MACE-POLAR source/ADT branches may be used only as frozen input
features in a capacity-matched ablation. They may not be added directly to the
new physical source. The first trainable implementation must reuse
`FieldEnergyFunctional` and the passive quadratic construction rather than
introducing a second hand-written source derivative.

The failed twelve-case relative-MEP gate is not reinterpreted. A follow-up gate
may retain the basis only if it is prospectively frozen around a continuum
reaction metric and a preallocated portion of the 1 kcal/mol end-to-end error
budget.
