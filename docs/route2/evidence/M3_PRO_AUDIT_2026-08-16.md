## Critical adoption, not deference

### Target-blind subspace

Let `X` be the frozen 306×18 geometry-only stock-area matrix, `D` its positive
column-L2 metric, and `theta_stock` the published water coefficients. M3 uses

```text
theta(alpha,beta) = alpha theta_stock + D^-1 [v1 v2] beta,
```

where `v1,v2` are the leading right singular vectors of
`(X D^-1)(I-q0 q0^T)` and `q0=D theta_stock/||D theta_stock||`. Local checks
reconstruct predictions under arbitrary positive unit reparameterizations and
verify metric orthogonality, rank, singular-vector gap, and exact three-column
reduced-design identity. No target or hybrid prediction is used here.

### Family rule

The Q4 single-link proposal was implemented as a target-blind canary and
rejected because it chained 176 of the 306 water rows into one component. Q7
then selected the exact heavy-element-count multiset equivalence, with an
all-element fallback only when a molecule has no heavy atom. On the frozen
geometry panel this yields 202 families, maximum size 7, and deterministic
ten-fold loads `[31,31,31,31,31,31,30,30,30,30]`.

The allowed claim is deliberately narrow: identical operational element-count
families do not cross folds. This is not scaffold, connectivity, homolog,
stereochemistry, or MCS generalization.

### LAD estimator and uniqueness

Each fold fits unweighted LAD only. Training columns are normalized to unit
L2 norm and the response is divided by `max(1, ||y||_inf)`. The reported LP
objective is independently recomputed as an L1 residual. Around that optimum,
six additional LPs minimize and maximize each scaled coefficient under

```text
Lcap = recomputed_L1 + 1e-8 * max(recomputed_L1, training_count).
```

A fold is rejected if any coefficient range exceeds
`1e-6*max(1,abs(minimum),abs(maximum))`, or if any primal, dual, KKT, range, or
cap check is inconclusive. There is no secondary anchor or ridge objective.
This certifies numerical near-point-identification under the frozen solver and
tolerances; it does not claim symbolic uniqueness over exact real arithmetic.

## Local verification boundary

Repository tests cover metric invariance, rank failure, geometry-only ZIP
access, deterministic unsplit family folds, balanced loading, pure-LAD recovery,
full-rank-but-nonunique LAD rejection, clustered bootstrap partitioning, and
self-rehashed preregistration-contract tampering. The actual 306-water OOF
result is generated only after this code and note are committed and an
external read-only preregistration is created from that clean Git identity.

Passing the development rule does not admit a production smooth-area CDS,
