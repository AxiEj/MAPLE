# Acetone point-multipole representation oracle

This is a target-free mechanistic falsification, not preregistered admission
evidence. It uses the already opened matched-QM acetone MEP and fits the best
hard-charge/dipole-constrained atom-centred point multipoles on three fixed
surface dilations.

The middle-shell held-out interpolation errors are approximately 25.29 percent
for l<=1, 24.06 percent for l<=2, and 23.95 percent for l<=3. The l<=3
coefficient norm also grows strongly. Thus merely adding point quadrupoles and
octupoles does not resolve near-field density penetration on this case.

The result may reject this point-multipole representation. It cannot admit a
new radial basis or make a chemical-accuracy claim.
