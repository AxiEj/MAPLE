# Current radial-GTO plus ADT replay on frozen nonuniform QM data

This replay reuses the preregistered twelve-molecule, four-point-charge-per-case
omegaB97M-V/def2-TZVPD response data. It replaces the historical four-channel
local-jet candidate with the exact current eight-channel radial-GTO field map
and decomposes original MACE-POLAR, removed radial residual, ADT, and their
current hybrid sum.

Mean weighted MEP response errors are 66.95 percent for original MACE-POLAR,
91.62 percent for the retained radial residual, 55.69 percent for ADT, and
46.45 percent for residual plus ADT. No branch passes the inherited 20 percent
gate on any of the twelve cases.

The replay itself was not preregistered, so it is retained only as a
falsification of the current profile. It reads no solvation target and cannot
admit a replacement model.
