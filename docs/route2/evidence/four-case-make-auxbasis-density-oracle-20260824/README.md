# Four-case auxiliary-density representation oracle

This no-solvation-target probe projects each frozen QM AO density into the
standard PySCF make_auxbasis Coulomb-fitting basis and imposes exact electron
count and electronic first moment through a cavity-independent Coulomb metric.

Across benzene, acetone, acetic acid, and 2-acetoxyethyl acetate, the constrained
area-weighted cavity-MEP error has mean 1.87 percent and maximum 2.68 percent.
All four are below the provisional 5 percent representation threshold.

The four QM MEP cases were already opened and the basis was first tried on
acetone, so this is not preregistered admission evidence. It justifies freezing
the same basis for a broader prospective representation panel. It does not
justify training, solvation accuracy, or a public capability.
