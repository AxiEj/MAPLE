## 2. Is monolithic PySCF+pyddx self-consistency necessary?

A **ddPCM-self-consistent density is mathematically necessary**. A monolithic PySCF+pyddx implementation is not.

Any algorithm is equivalent if it returns the same selected stationary solution of the same discrete functional

[
\mathcal F_{\rm dd}[\gamma]
===========================

E_0[\gamma]+G_{\rm dd}[\gamma].
]

For example, an external alternating loop is admissible:

[
\gamma^{(k)}
\longrightarrow
b(\gamma^{(k)})
\longrightarrow
\sigma^{(k)}
\longrightarrow
V_{\rm reac}^{(k)}
\longrightarrow
\gamma^{(k+1)},
]

provided it converges to the same stable stationary branch and the reaction operator is the derivative of the same (G_{\rm dd}).

Once (\gamma_{\rm vac}) and (\gamma_{\rm pcm}) have been obtained, the decomposition itself can be evaluated entirely by frozen-density postprocessing. Thus:

* self-consistency is necessary to obtain (\gamma_{\rm pcm});
* self-consistency is not necessary for each subsequent component evaluation.

### Necessary and sufficient equivalence conditions

A separately generated pair ((\widetilde\gamma_{\rm vac},\widetilde\gamma_{\rm pcm})) is equivalent to the integrated calculation exactly when:

1. (\widetilde\gamma_{\rm vac}) belongs to the selected minimizer or stationary branch of (E_0);
2. (\widetilde\gamma_{\rm pcm}) belongs to the selected stable stationary branch of (E_0+G_{\rm dd});
3. the electronic Hamiltonian, basis, integral conventions, XC grids, charge, multiplicity, and occupation constraints are identical;
4. the nuclear potential, cavity, radii, dielectric parameters, (A), boundary projector, surface metric, and continuum scalar are identical;
5. the reaction operator used to relax (\widetilde\gamma_{\rm pcm}) is the exact derivative of that same discrete (G_{\rm dd});
6. any multiple-SCF-solution branch rule is identical and target-independent.

Operationally, require both a small projected SCF commutator and a positive orbital-stability test on the selected branch. Equality of final energies alone is insufficient because distinct densities can occasionally produce near-identical scalar energies.

### Why IEFPCM-relaxed density followed by ddPCM evaluation is invalid

Let (\gamma_{\rm IEF}) be relaxed under IEFPCM/GEPOL. The hybrid quantity

[
E_0[\gamma_{\rm IEF}]
+
G_{\rm dd}[\gamma_{\rm IEF}]
----------------------------

E_0[\gamma_{\rm vac}]
]

is a mixed trial-density evaluation. It is not the ddPCM stationary energy because generally

[
\left.
\frac{\delta}{\delta\gamma}
\left(E_0+G_{\rm dd}\right)
\right|*{\gamma*{\rm IEF}}
\ne 0.
]

Consequently:

* (E_0[\gamma_{\rm IEF}]-E_0[\gamma_{\rm vac}]) is an **IEFPCM-induced** distortion cost;
* (G_{\rm dd}[\gamma_{\rm IEF}]) is ddPCM stabilization of the wrong relaxed density;
* their sum is not (T_{\rm QM}^{\rm ddPCM});
* its coordinate derivative is not the stationary ddPCM derivative;
* it cannot decide (\Phi_0) versus (\Phi_{\rm raw}).

If the ddPCM functional has a global minimum and (\gamma_{\rm IEF}) lies in the same admissible space, the mixed value is merely a trial-state upper bound to the ddPCM minimum. It may be reported as a post-decision sensitivity test, never as the matched reference.

## 3. Continuum-active source norm and exact energy error

Let

[
b_{\rm ML}
==========

B_pc_p+B_g\delta c_g,
\qquad
b_{\rm QM}
==========

b_{\rm QM}(\gamma_{\rm pcm}),
\qquad
\delta b=b_{\rm ML}-b_{\rm QM}.

Both must live in the same ddPCM boundary space.

### Energy-self-adjoint discretization

Assume

[
A^TW=WA
]

and that there is a fixed (s\in{+1,-1}) such that (sA) is positive definite in the (W)-inner product on the continuum-active subspace. For a stabilizing convention with (G<0), normally (s=-1).

Define the active source norm

[
\boxed{
|b|_{\rm act}^2
===============

# s,b^TWA^{-1}b

2|G(b)|
}
]

on the active quotient. Only an analytically known exact gauge nullspace may be quotiented out. Data-dependent eigenvalue deletion or spectral clipping is not admissible. If an unexplained numerical nullspace or indefiniteness remains, the norm-based audit fails closed.

The fixed-source energy error is exactly

[
\boxed{
\Delta G_{\rm src}
==================

# G(b_{\rm ML})-G(b_{\rm QM})

\left\langle
\delta b,
A^{-1}\frac{b_{\rm ML}+b_{\rm QM}}{2}
\right\rangle_W
}
]

or, equivalently,

[
\Delta G_{\rm src}
==================

\langle\delta b,A^{-1}b_{\rm QM}\rangle_W
+
\frac12\langle\delta b,A^{-1}\delta b\rangle_W.
]

Cauchy–Schwarz in the active norm gives

[
\boxed{
|\Delta G_{\rm src}|
\le
|\delta b|*{\rm act}
\left(
|b*{\rm QM}|*{\rm act}
+
\frac12|\delta b|*{\rm act}
\right)
}
]

and also

[
|\Delta G_{\rm src}|
\le
|\delta b|*{\rm act}
\frac{
|b*{\rm ML}|*{\rm act}+|b*{\rm QM}|_{\rm act}
}{2}.
]

For

[
\eta_b
======

\frac{|\delta b|*{\rm act}}
{|b*{\rm QM}|_{\rm act}},
]

the relative polarization-energy bound is

[
\boxed{
\frac{|\Delta G_{\rm src}|}{|G(b_{\rm QM})|}
\le
2\eta_b+\eta_b^2
}
]

when (b_{\rm QM}\ne0).

This is the correct source diagnostic. Euclidean coefficient error is not physically meaningful because different boundary harmonics and surface elements have different continuum leverage.

### Non-Euclidean metrics and nonsymmetric (A)

The formulas already allow an arbitrary SPD surface metric (W).

For nonsymmetric (A), define the symmetric energy kernel

[
H
=

\frac12
\left(
WA^{-1}+A^{-T}W
\right).
]

Because the antisymmetric part vanishes in a scalar quadratic form,

[
G(b)
====

\frac12b^THb.
]

The exact source-energy error becomes

[
\Delta G_{\rm src}
==================

\delta b^TH\frac{b_{\rm ML}+b_{\rm QM}}2.
]

If (sH) is positive definite on the active quotient, use

[
|b|_{\rm act}^2=s,b^THb
]

and the same bounds follow.

If (sH) is not positive definite, no (A^{-1})-energy norm exists. One may still report the exact signed (\Delta G_{\rm src}), and an operator-norm bound under an independently frozen SPD metric (M_0),

[
|\Delta G_{\rm src}|
\le
|\delta b|*{M_0}
,
\left|
M_0^{-1/2}HM_0^{-1/2}
\right|*2
,
\left|
\frac{b*{\rm ML}+b*{\rm QM}}2
\right|_{M_0},

but the coercive active-norm admission gate is unavailable.

For a still more general discretization with distinct right and left source maps,

[
A\sigma=Bx,
\qquad
G(x)=\frac12x^TC^TW\sigma,
]

the energy kernel is

[
H_x
===

\operatorname{sym}
\left(C^TWA^{-1}B\right).
]

The diagnostic must be conducted in the (x)-space induced by (H_x), or after transforming both sources into a common energy-dual boundary representation.

A nonsymmetric PCM SCF must also use the derivative (H b), not blindly (WA^{-1}b). Otherwise the alleged QM/ddPCM reference is itself nonvariational and cannot support the requested decomposition.

## 4. Fair error-separation protocol

At the matched geometry and ddPCM discretization, define

[
b_Q^0=b_{\rm QM}(\gamma_{\rm vac}),
\qquad
b_Q^*=b_{\rm QM}(\gamma_{\rm pcm}),
\qquad
\delta b_Q=b_Q^*-b_Q^0.
]

Solve

[
A\sigma_Q^*=b_Q^*,
\qquad
u_Q=L\sigma_Q^*.
]

The quantity (u_Q) is only the checkpoint-native receiver applied to the matched QM surface solution. It is not asserted to be an energy-dual QM field.

For the ML model, define

[
b_P=B_pc_p,
\qquad
r(u)=B_g\delta c_g(R,u),
]

and solve the operational root

[
u^*
===

LA^{-1}\left[b_P+r(u^*)\right].
]

Then the total boundary-source discrepancy has the exact decomposition

[
\boxed{
b_{\rm ML}^*-b_Q^*
==================

e_P+e_R+e_F
}
]

with

[
e_P=b_P-b_Q^0,
]

[
e_R=r(u_Q)-\delta b_Q,
]

[
e_F=r(u^*)-r(u_Q).
]

These have distinct meanings:

* (e_P): permanent-source error;
* (e_R): response-map error at a common receiver input;
* (e_F): operational-root or feedback error.

This cleanly separates the model response from the error caused by solving its own nonvariational root.

For cancellation-resistant energy attribution, preregister the order

[
b^{(0)}=b_Q^*,
\quad
b^{(1)}=b^{(0)}+e_P,
\quad
b^{(2)}=b^{(1)}+e_R,
\quad
b^{(3)}=b^{(2)}+e_F=b_{\rm ML}^*.
]

Each exact increment

[
\Delta G_j=G(b^{(j)})-G(b^{(j-1)})
]

is reportable. The increments are order-dependent because the energy is quadratic, so the order must not be changed after results are seen.

A cancellation-free upper bound is

[
B_{\rm split}
=============

\sum_{j=1}^{3}
|e_j|*{\rm act}
\left(
|b^{(j-1)}|*{\rm act}
+
\frac12|e_j|_{\rm act}
\right).
]

It guarantees

[
|G(b_{\rm ML}^*)-G(b_Q^*)|
\le B_{\rm split}.
]

### Continuum operator and cavity error

These must be tested with a **fixed continuous QM charge density**, not a common raw boundary vector, because different cavities and solvers have different boundary spaces.

For a fixed (\gamma), define (G_{A,C}[\gamma]). Then:

[
\Delta_{\rm operator}
=====================

G_{A_2,C_1}[\gamma]-G_{A_1,C_1}[\gamma]

changes the equation while holding the cavity and density fixed, and

[
\Delta_{\rm cavity}
===================

G_{A_2,C_2}[\gamma]-G_{A_2,C_1}[\gamma]

changes the cavity while holding the equation and density fixed.

If the implementations cannot realize the same cavity in both solvers, only a combined operator-plus-cavity discrepancy is identifiable. Reoptimizing (\gamma) after each swap combines continuum and electronic-response effects and is a different, secondary experiment.

## 5. What can (\Delta E_{\rm raw}) legitimately be compared with?

It cannot be admitted as an estimate of (D_{\rm QM}).

The reasons are structural:

1. (D_{\rm QM}) is the vacuum QM functional evaluated on two explicit electronic densities.
2. (E_{\rm raw}) exposes no corresponding electronic state (\gamma(u)) on which the same vacuum functional can be evaluated.
3. The uniform-field audit proves only that the raw scalar omits a separately added uniform (+E!\cdot!\mu) term.
4. There is no identified nonuniform explicit-work functional.
5. Therefore the uniform result cannot be extrapolated into an unobserved nonuniform decomposition.

A table of (\Delta E_{\rm raw}) and (D_{\rm QM}) may be shown as an exploratory numerical juxtaposition, but their difference must not be an admission criterion and numerical agreement must not be called component validation.

The strongest admissible QM comparison is

[
\boxed{
\Delta E_{\rm raw}+G_{\rm ML}
\quad\text{versus}\quad
T_{\rm QM}.
}
]

The strongest model-internal test is the native radial charging curve

[
W_{\rm raw}(\lambda)
====================

E_{\rm raw}(R,\lambda u^*)-E_{\rm raw}(R,0),
\qquad 0\le\lambda\le1,
]

with

[
\frac{dW_{\rm raw}}{d\lambda}
=============================

D_uE_{\rm raw}(R,\lambda u^*)[u^*]

and

[
\boxed{
W_{\rm raw}(1)
==============

\int_0^1
D_uE_{\rm raw}(R,\lambda u^*)[u^*],d\lambda.
}
]

This verifies that the raw contribution is a well-defined model-native scalar along the declared path. It does not turn that scalar into a source–field work or a QM distortion energy. No term of the form (\langle c,u\rangle) is restored.

## 8. Multiple solvents, coordinate VJPs, adjoints, and CDS separation

For solvent (s), write the operational root in block form with

[
z=(\sigma,q,u),
\qquad
q=\delta c_g(R,u),
]

[
F_s(R,z)=
\begin{bmatrix}
A_{R,s}\sigma-B_{p,R,s}c_p(R)-B_{g,R,s}q\
q-\left[M_{\rm POLAR}(R,u)-M_{\rm POLAR}(R,0)\right]\
u-L_{R,s}\sigma
\end{bmatrix}
=0.
]

Each solvent has its own hash-bound (A_s,B_{p,s},B_{g,s},L_s), cavity, dielectric data, and radii. The ledger equations and decision budgets remain unchanged across solvents. No solvent-specific rescaling is introduced.

For either declared scalar (\phi_k(R,z)), solve the block adjoint

[
\left(\partial_zF_s\right)^T\lambda_k
=====================================

\left(\partial_z\phi_k\right)^T.
]

Then

[
\boxed{
\frac{d\Phi_k}{dR}
==================

## \partial_R\phi_k

\lambda_k^T\partial_RF_s.
}
]

This requires analytic coordinate VJPs for (A), (B_p), (B_g), (L), the cavity/radii construction, the permanent source, the induced source, and—only for (\Phi_{\rm raw})—the native-field derivative of (E_{\rm raw}).

No source–field endpoint pairing is added to the adjoint.

If the root is locally unique and (C^1), and the adjoint differentiates the exact declared scalar, the resulting force is conservative for that operational scalar. That remains logically distinct from a stationary electronic–continuum functional and does not reopen Tier V.

A separately versioned CDS or nonpolar scalar may later be added as

[
\Phi_{\rm operational,total}
============================

\Phi_{\rm selected}
+
\Psi_{\rm CDS}^{(v)}
+
\Psi_{\rm other}^{(v)}.
]

Its value and force are audited independently. It is absent from the matched QM/ddPCM decision and cannot repair a failed electrostatic ledger.
