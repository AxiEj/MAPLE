# VQM24 response-only CPKS pilot

The four already opened rare-element Gate-B records pass every MEP, dipole,
CPKS residual, checkpoint, electron-count, reciprocity and passivity gate.  The
previous phosphorus energy-curvature failure is retained but excluded from this
new assessment because numerical curvature was already forbidden as a training
target before the 32-record observable batch.  This pilot authorizes only a
preregistered 32-record CPKS-versus-finite-field coverage run; it does not yet
admit CPKS as the expanded-response generator.
