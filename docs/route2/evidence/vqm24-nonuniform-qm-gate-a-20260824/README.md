# VQM24 nonuniform-field QM Gate-A

Status: `pass-numerical-gate-a`.

Five frozen train records cover F, P, S, Cl, and Br under one common RKS omegaB97M-V/def2-TZVPD and PySCF level-3 grid protocol. The gate checks numerical response consistency only. It does not train or evaluate a model, read VQM24 energy labels or experimental solvation targets, use PCM/cavity labels, or admit a MAPLE capability.
